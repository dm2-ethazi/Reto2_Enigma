# Pair programming · colaboración técnica

El pair programming es una práctica de programación colaborativa: **dos personas trabajan juntas sobre el mismo problema**. El *driver* escribe el código y el *navigator* revisa alternativas, riesgos y decisiones; los roles **se intercambian** a mitad de la sesión.

No sustituye a las ceremonias de Scrum ni es un requisito de Scrum: es la forma acordada en el reto para compartir conocimiento y revisar los puntos complejos del contrato R2AE.

## Requisito del Reto 2

- **Dos sesiones por sprint** y **cuatro en total**.
- Duración de **40–50 minutos** por sesión.
- **Rotación de roles** dentro de la sesión (no vale que uno haga siempre de driver).
- En cada sprint **cada integrante debe pasar por los dos roles**.
- Cada sesión deja **evidencia** enlazada: la coautoría de commits complementa el registro, pero no demuestra por sí sola que se trabajó en pareja.

## Evidencias mínimas de cada sesión

| Campo | Descripción |
|---|---|
| Fecha y duración | Día de la sesión y minutos reales |
| Issue | Issue del tablero sobre la que se trabajó |
| Participantes y roles | Quién empieza como driver y quién como navigator |
| Intercambio de funciones | Minuto del cambio y quién pasa a cada rol |
| Decisión técnica | La decisión concreta que se tomó y por qué |
| Resultado | Qué quedó hecho (prueba, corrección, refactor) |
| Enlace a código o PR | Commits, PR o archivo donde se ve el resultado |

```markdown
- Fecha: AAAA-MM-DD · Duración: 45 min
- Issue: #NN — <título>
- Participantes: A (driver 0–22, navigator 22–45) · B (navigator 0–22, driver 22–45)
- Decisión técnica: <qué se decidió y por qué>
- Resultado: <qué quedó hecho>
- Evidencias: <enlaces a PR, commit o archivo>
```

## Buenas prácticas acordadas

- Compartir pantalla y turnarse el teclado de verdad; el navigator no se limita a mirar.
- Anotar la decisión técnica **al terminar**, no al final del sprint.
- Si la sesión se alarga más de 50 minutos, se registra igualmente el tiempo real y se justifica.
- Enlazar siempre la Issue: el professorado contrasta el registro con el historial de GitHub.
